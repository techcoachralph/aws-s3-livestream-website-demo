Automated S3 Deployment via GitHub Actions & AWS OIDC

This website is automatically built and deployed to a new Amazon S3 bucket using GitHub Actions and an AWS OpenID Connect (OIDC) identity provider.

Instead of manually uploading static files or storing risky, long-lived AWS secret access keys in GitHub Secrets, our deployment pipeline uses modern short-lived federated credentials.

How This Deployment Works:

  1. Code changes are pushed or merged into the main branch.
  2. GitHub Actions requests a short-lived OIDC JSON Web Token (JWT).
  3. AWS STS verifies the token against the AWS IAM OIDC identity provider.
  4. GitHub Actions assumes an IAM role and syncs all website assets directly to the target S3 bucket.
