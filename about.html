About This Demonstration

Hosting a website on Amazon S3 is one of the most cost-effective, reliable, and scalable ways to host client-side web applications.

Key highlights of S3 static hosting include:

  • High Availability: Built on AWS's durable object storage.
  • Serverless: No EC2 instances or web servers to maintain or patch.
  • Custom Error Support: S3 lets you specify a custom error document (like error.html) for 4XX errors.
